# Règles du jeu

Les règles de jeu du système Cardenveil, en français, telles qu'elles sont implémentées par le plugin. Cette section est destinée aux joueurs et aux meneurs : elle décrit ce que le moteur de dés doit afficher, pas la façon dont le code est organisé.

* [Jets de dégâts](damage-rolls.md) — formule complète des jets d'attaque : Seuil de Miss, critiques explosifs, Avantages/Désavantages, Engagement, Gobelins, Haches et affichage du détail.
