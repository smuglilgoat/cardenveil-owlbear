# Cardenveil 2.3.1 — correctifs

## 🗡️ Correctifs

* **Vider une main ne vide plus l'autre** : sur les fiches importées (armes sans emplacement enregistré), cliquer **Vider** sur l'arme en main principale retirait aussi l'arme de la main secondaire du paper-doll — c'est corrigé, l'arme secondaire garde désormais sa place (et son emplacement est mémorisé)
* **Icônes des armes dans le Sac** : les jetons d'armes non équipées affichent maintenant leur **icône** (celle définie sur l'arme elle-même, sinon celle de l'objet d'inventaire associé) au lieu d'un simple jeton sans image
