# Cardenveil 2.7.17 — don d'équipement

## ✨ Amélioré

- **La liste « Donner à » ne propose que les joueurs connectés** : elle suit la table en direct, donc plus de transfert possible vers un joueur qui a quitté la partie. Le personnage du MJ reste proposé quand il existe.
- **Portrait dans la liste** : chaque nom est accompagné du portrait de sa fiche (image ou emoji) ; sans portrait, une pastille colorée portant l'initiale du joueur le remplace.
- **Liste défilante** : elle défile quand la table est nombreuse.
