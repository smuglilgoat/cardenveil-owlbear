# Notes de version

Tout ce qui change dans Cardenveil, version par version. Les notes sont écrites pour les joueurs et le MJ : ce qui est nouveau, ce qui est corrigé, et ce qu'il faut faire après une mise à jour (le plus souvent, recharger la table une fois).

La version la plus récente est en haut. Les versions qui ne font que corriger
la même chose sont regroupées sur une seule page (par exemple 2.7.1 → 2.7.15) :
chaque point y indique alors la version où le correctif est arrivé.

* **Notes complètes** — tout ce qui a changé depuis la 2.6.0, regroupé par thème plutôt que par version.
