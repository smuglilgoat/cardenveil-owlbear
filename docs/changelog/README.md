# Notes de version

Tout ce qui change dans Cardenveil, version par version. Les notes sont écrites pour les joueurs et le MJ : ce qui est nouveau, ce qui est corrigé, et ce qu'il faut faire après une mise à jour (le plus souvent, recharger la table une fois).

Chaque version mineure a sa page et rassemble tous ses correctifs. La version
mineure la plus récente est en haut, et dans une page les versions se suivent de
la plus récente à la plus ancienne, chacune dans sa section : les notes d'une
2.10.3 se lisent donc dans la page 2.10, au-dessus de celles de la 2.10.0. Les
correctifs qui se succèdent sur le même sujet restent groupés dans une seule
section (par exemple 2.7.1 → 2.7.15), où chaque point indique la version où le
correctif est arrivé.
