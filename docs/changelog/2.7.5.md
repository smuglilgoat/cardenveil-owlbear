# Cardenveil 2.7.5 — largeur du popover adaptée à la main

## Popover de main : largeur adaptée à la main

* **Fini la barre large pour rien.** La largeur minimale du popover était fixée à 560 px : une main de 2 ou 3 cartes (éventail de 352 px) se retrouvait avec une barre plus large que les cartes, qui mangeait la table. La largeur suit maintenant **ce que la barre affiche réellement** :
  * base **360 px** (Replier + 🎨 + Piocher + 4 tokens compacts) ;
  * `+130 px` pendant une consigne de sélection (« cliquez la carte… ») ;
  * `+80 px` pour la pastille d'échange en attente ;
  * `+34 px` pour le bouton 🍄 Sporelin. Mesures attendues : main de 3 cartes `360x178` (au lieu de `560x178`), main de 13 cartes inchangée (`992x179`).
* **Tokens compacts** : `F3`, `A2`, `E1`, `S0` (lettre + compteur), le `3/3` complet et le nom du token dans l'info-bulle — c'est ce qui permet la barre à 360 px (c'est aussi la forme validée dans la maquette).

## Diagnostic

* Le 🔍 Diag ne perd plus les boutons de la barre : `overflow-x: auto` calcule aussi `overflow-y` en `auto`, donc le test « élément dans une zone défilante » excluait toute la barre (dernier instantané : `interactive.count: 1`). Seules les zones qui défilent **verticalement** (onglets de fiche, longues listes) sont ignorées désormais.
