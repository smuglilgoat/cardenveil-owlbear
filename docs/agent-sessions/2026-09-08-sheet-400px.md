# Agent Session — 2026-09-08 — Character sheet 400px adaptation

## Goal
User feedback: the Figma-proportioned character sheet is too cramped in the ~400px
Owlbear Rodeo side panel. Make the layout adaptive while keeping the exact prototype
layout when there is room.

## Approach
Tailwind 4 **container queries** (`@container` on root + `@2xl:` variants = width
>= 42rem/672px). Base styles = compact stacked layout; `@2xl:` restores the
prototype layout. Chosen over viewport media queries so it adapts to the actual
component width (also correct if the sheet is ever hosted in a floating window).

## Changes (src/lib/CharacterSheet.svelte only, 28/28 line pairs)
- Root: `@container` added.
- Top bar: identity summary `hidden @2xl:block`; IMPORTER/SUPPRIMER/ANNULER/
  SAUVEGARDER `px-2 @2xl:px-3`; ÉDITION `px-2.5 @2xl:px-4`.
- HP block `w-full @2xl:w-[358px]`; identity extras grid `grid-cols-2 @2xl:grid-cols-4`.
- Defense row `grid-cols-2 @2xl:grid-cols-3`, Parade `col-span-2 @2xl:col-span-1`
  (Initiative + Mouvement share a row at 400px).
- Pills row `grid-cols-2 @2xl:grid-cols-5`, TOTEM pill full width at base.
- Compétences + Narratif `grid-cols-1 @2xl:grid-cols-2`; equipment `grid-cols-2 @2xl:grid-cols-3`.
- Capacity card: image `w-14 h-14 @2xl:w-20 @2xl:h-20`, dice button
  `w-16 h-9 text-sm @2xl:w-24 @2xl:h-12 @2xl:text-base`, `?` help `hidden @2xl:block`.
- Edit-form grids: cost grid 2→4 cols, dice/incant/save + weapon grids 2→3 cols.
- Inventory item notes column `w-24 @2xl:w-52` (truncated).
- Content viewport `mx-2 @2xl:mx-4`; bottom nav `grid grid-cols-3 p-2` at base
  (3×2 buttons), `@2xl:flex @2xl:h-16` single row; modals `w-[92%] max-w-md`.
