# Session — 2026-09-30 — 3D physics dice for attack rolls

## Goal
Attacks (compact-popover attack panel) were pre-rolled flat; implement 3D physics
dice without losing the rules' staged semantics (miss threshold, crit explosions
with decaying advantage, Hache 2dX doubles chaining, Finesse repeats).

## Approach
Staged seeded throws driven by the roller client: the rule walk is extracted
once (`runAttack`) with an injectable per-stage dice source; the 3D driver
throws each stage through the existing intent pipeline and reads the values off
the settled Rapier physics. Conditional explosions are therefore honest physics.
