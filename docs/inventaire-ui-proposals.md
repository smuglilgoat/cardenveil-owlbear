# INVENTAIRE tab — UI redesign suggestions

> Generated by **GLM-5.3-Flash** (planner session, 2026-09-14). Proposals only — nothing implemented.
> All mockups assume the current design language: `#111827` cards on `#242424`, colored left-border accents
> (`itemTypeColor`: Arme red, Armure blue, Consommable green, Équipement amber, Divers gray), indigo
> equipped badges, Tailwind utilities, French labels.

---

## Current state (baseline)

```
┌──────────────────────────────────────┐
│ ÉQUIPEMENT                           │
│ ┌──────────┐ ┌──────────┐ ┌────────┐ │
│ │ ⛑ Casque │ │ 🛡 Plastr│ │ 🥾 Bot │ │  ← 7 slot cards, 2/3 cols
│ │ summary… │ │ summary… │ │ …      │ │     clamped description
│ └──────────┘ └──────────┘ └────────┘ │
│ Arme | familles…        (group row)  │  ← type header rows
│ • Objet          val   notes…        │  ← cramped single-line items
│ Armure | …                           │
│ ARMES                                │
│ [Équipée] Épée  1d8 +3               │
│   de: 1d8 · portée: … (truncated)    │  ← field join cut off
└──────────────────────────────────────┘
```

Pain points: no section hierarchy, item rows cramped against group rows, weapon properties
truncated to one line, empty slots indistinguishable from filled ones, no counts at a glance.

---

## Proposal A — Sectioned panels (recommended)

Three breathing sections with colored section headers. Equipment stays a 2/3-col grid but roomier;
inventory becomes type-block lists; weapons become hero cards with a 2-col stat grid.

```
┌──────────────────────────────────────┐
│ ▌ÉQUIPEMENT              5/7 portés  │  ← colored bar + equipped count
│                                      │
│ ┌────────────────┐ ┌────────────────┐│
│ │ ⛑ Casque       │ │ 🛡 Plastron    ││  ← icon + slot label (7px gray)
│ │ Heaume d'acier │ │ Cuirasse       ││  ← item name (bold)
│ │ vol +1         │ │ defl +2        ││  ← summary line
│ │ …description   │ │ …description   ││  ← clamped 2 lines, rich HTML
│ │   sur 2 lignes…│ │ …              ││
│ └────────────────┘ └────────────────┘│
│ ┌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐                  │  ← empty slot: dashed border,
│ │ ⚪ Anneau  vide │                  │     muted, click still fills via edit
│ └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘                  │
│                                      │
│ ▌SAC                                 │
│                                      │
│ ▌CONSOMMABLE ─────────────── 3 objets│  ← type header with count
│ ┌──────────────────────────────────┐ │
│ │ • Potion de soin         x2      │ │  ← dot in type color, qty bold
│ │ • Parchemin de feu               │ │  ← notes on second line, not cut
│ └──────────────────────────────────┘ │
│                                      │
│ ▌ARMES ──────────────────── 2/2 équip│
│ ┌──────────────────────────────────┐ │
│ │ ÉQUIPÉE  Épée longue        1d8  │ │  ← badge + name + DE right
│ │ ╔════════════╗ ╔════════════╗   │ │
│ │ ║ BONUS  +3  ║ ║ PORTÉE  —  ║   │ │  ← stat grid 2-col, boxed values
│ │ ╚════════════╝ ╚════════════╝   │ │
│ │ Propriétés: finesse, polyvalente │ │  ← free-flowing, wraps, not cut
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

Key moves: section headers with counts; dashed empty slots; weapon properties on their own
multi-line block; boxed stat grid for DE/BONUS/PORTÉE. Vertical rhythm via section spacing (mt-5)
instead of hairlines everywhere.

## Proposal B — Two-column @2xl with slot rail

A narrow left rail with all 7 equipment slots stacked as compact rows (click to expand in place);
right column carries SAC and ARMES. Single-column fallback on narrow panels stacks everything
(same content order as A).

```
narrow panel: identical to Proposal A, stacked
@2xl (wide):
┌───────────────┬────────────────────┐
│ ▌ÉQUIPÉ       │ ▌SAC               │
│ ⛑ Casque  +1  │ ┌────────────────┐ │
│ 🛡 Plastron +2 │ │ Potion de soin │ │
│ 🥾 Bottes +3m │ │ x2 · notes…    │ │
│ 💍 Anneau  —  │ └────────────────┘ │
│ 🧤 Gantelets  │                    │
│ 📿 Amulette   │ ▌ARMES             │
│ ───────────── │ ┌────────────────┐ │
│ (clic = fiche │ │ ÉQUIPÉE Épée   │ │
│  du slot,     │ │ 1d8 +3         │ │
│  détail différé)│ │ propriétés…   │ │
│               │ └────────────────┘ │
└───────────────┴────────────────────┘
```

Key moves: 7 slots always visible without scrolling (tallest content wins the fold);
the rail reads like a "worn gear" checklist. Cost: needs a `@2xl:grid-cols-[180px_1fr]` split
and careful expand-in-place height handling.

## Proposal C — Data-sheet tables

Most information-dense. One line per item with aligned columns; collapsible type sections.

```
┌──────────────────────────────────────┐
│ ▌ÉQUIPEMENT                          │
│   Casque   Heaume d'acier    vol +1  │
│   Plastron Cuirasse         defl +2  │
│   Bottes   Bottes de vitesse vit +3  │
│   (1 ligne par slot · clic = détail) │
│                                      │
│ ▌ARMES          DE     BONUS  NOTES  │
│ ──────────────────────────────────── │
│ ● Épée longue  1d8    +3     finesse │
│ ● Arc court    1d6    +2     distance│
│   (ligne cliquable → détail déroulé) │
│                                      │
│ ▌CONSOMMABLE (3)                     │
│   Potion de soin            x2       │
│   Parchemin de feu          x1       │
│                                      │
│ ▌DIVERS (5)                      ▾   │
│   (section repliable)                │
└──────────────────────────────────────┘
```

Key moves: column headers for weapons, tabular alignment (`tabular-nums`), collapsible groups
for DIVERS-type hoarding. Least "cardy" — reads fastest for big inventories, but loses the
card aesthetic used elsewhere in the sheet.

## Comparison

| Criterion | A — Panels | B — Rail | C — Tables |
|---|---|---|---|
| Readability | ★★★ | ★★☆ | ★★★ |
| Breathability | ★★★ | ★★★ | ★☆☆ |
| Info density | ★★☆ | ★★☆ | ★★★ |
| Fits narrow panel | ★★★ | ★★☆ (stacks) | ★★★ |
| Consistency with rest of sheet | ★★★ | ★★★ | ★★☆ |
| Implementation effort | Medium | Medium-high | Low-medium |

Recommendation: **A**, borrowing the collapsible type sections from C for DIVERS if item counts grow.
